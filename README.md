## About me

I build small, practical, and accessible tools that work directly in the browser.

My projects focus on privacy, simplicity, and transparency: no unnecessary backend, no hidden tracking, and no complicated setup when a plain web page can do the job.

> **Open source should be easy to understand, easy to use, and easy to improve.**

## Project principles

<table width="100%">
<tr>
<td width="50%" valign="top">

### Privacy by default

- Process data locally whenever possible
- Avoid unnecessary uploads
- No analytics or telemetry
- No forced accounts
- No hidden tracking

</td>
<td width="50%" valign="top">

### Simple by design

- Plain HTML, CSS, and JavaScript
- Minimal dependencies
- No complicated build process
- Clear documentation
- Easy to fork and modify
